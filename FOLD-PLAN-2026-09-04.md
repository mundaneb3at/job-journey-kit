# FOLD PLAN — job-journey-kit v2 (2026-09-04)

What is being folded in from two upstream projects, item by item. **Method and prompts only** — no
code, no dependencies, no setup script is copied or run (the kit's "no dependencies beyond Node 18+
for the sweep tool" promise stays literally true).

## Upstreams

| Project | URL | License | Default branch | How it was read |
|---|---|---|---|---|
| career-ops | https://github.com/career-ops-hq/career-ops | MIT | `main` | read-only GET over `raw.githubusercontent.com` + `gh api` (2026-09-04). Never installed, never run. |
| ai-job-search | https://github.com/MadsLorentzen/ai-job-search | MIT | `master` | same |

Both write personal data into tracked files at setup time, so neither was executed on this machine.

**One inherited claim corrected:** a second-hand note described career-ops as an "A–H evaluation".
The live prompt (`batch/batch-prompt.md`) is **Step 0 archetype detection + Blocks A–G + a Risk
Summary**. There is no Block H. This fold follows the repo, not the note.

## Deliberately NOT folded

| Item | Why not |
|---|---|
| `npx @santifer/career-ops init`, `/setup`, any installer | Both write personal data into tracked files at setup. Never run here. |
| LaTeX CV/cover templates, `lualatex`/`xelatex` compile-and-inspect loops, PDF page-break rules | Adds a full TeX distribution as a dependency. The kit's résumé stays one markdown file. |
| Bun / Python 3.10+ / TypeScript board-scraper CLIs (`jobbank-search`, `jobindex-search`, `linkedin-search`, …) | The kit already proves liveness with `tools/ats-sweep.mjs`, zero deps. |
| `salary_lookup.py`, Gmail sync, Notion sync, HTML report, Opik tracing, plugin registry | Accounts, keys, or a dependency for each. |
| Company-research JSON cache schema, tracker TSV rows, `seen_jobs.json` state machine | Overlaps the kit's existing `OPPORTUNITY-TRACKER.md` + `VERIFY-LEDGER-<date>.md`. Two queues is the failure mode the kit's Layer-3 rule exists to prevent. |
| career-ops archetype table contents (AI Platform / LLMOps, Agentic Workflows, …) | Specific to one author's target market. Shipping it would make the kit an AI-jobs kit. The method is kept; the rows are the reader's to write. |
| 0–100 weighted fit scores, Strong/Good/Moderate/Weak bands | **Contradicts the kit's own rule**: hard filters are quoted verbatim, never compressed into a fit percentage. A weighted score is exactly the compression that lost a deadline. Kept out on purpose. |

## Gates checked before this shipped

- **Privacy:** nothing owner-specific in any new file — no personal name, employer, résumé number,
  school, or ledger row. The kit stays method-only.
- **License:** MIT text is never relicensed CC0. The one verbatim sentence ships quoted and
  attributed, in `THIRD-PARTY.md` and at its point of use. Everything else is paraphrase.
- **Dependencies:** none added. No new runtime, no setup step, no account.
- **Internal consistency:** nothing folded in contradicts the kit's three existing rules — and the
  refused fit score above exists precisely because it would have.
